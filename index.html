06 / PRINCIPLES

How we build

Three rules every Delfos Hub product follows, from the first commit to mainnet.

01 Your keys, your assets Nothing we ship holds user funds or private keys on a server. You sign, you own.
02 On-chain first State that matters lives in smart contracts on Terra Classic, not in a database we control.
03 Verify, don't trust Open code and reproducible contract builds, so anyone can check the checksum themselves.
